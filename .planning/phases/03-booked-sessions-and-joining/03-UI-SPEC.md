# Phase 03 — UI Design Contract

> Visual and interaction contract for Phase 03: Booked Sessions and Joining. Generated by gsd-ui-researcher, to be verified by gsd-ui-checker.
>
> **Scope of this contract.** Phase 03 is a bug-fix phase on a live SwiftUI app. It adds no palette, no spacing scale and no redesign. It locks (1) the design system exactly as the code has it today, inherited from `02-UI-SPEC.md` and not re-derived, and (2) the new or changed states, copy and interactions the 17 Phase 03 requirements need: one new card on a screen that lacks it, one new transient confirmation, a handful of new buttons and lines of copy, and rules for when existing controls show or hide. Pre-existing geometry and text styling that Phase 03 does not touch are out of contract (see the two "Out of contract" notes).
>
> **Every copy string in the Copywriting Contract is exact.** Where a string comes from `03-CONTEXT.md`, the decision id is cited. Where it comes from Android, the Android key is cited. Money in copy is shown as `CA$45.00` for illustration; the real value always comes from the shared `Money` formatter (Phase 2 D-09).

Why the `RESCHEDULE_OUTSIDE_AUTH_WINDOW` line changed. The line must not name 24 hours, because two of the three causes are unrelated to timing.

SIGN-05 (inventory S6): the profile photo preview applies the zoom slider (`scaleEffect(1 + zoom)` on a centred, filled circle), but Save uploads the whole original image re-encoded, so the uploaded avatar does not match what the user set. Render the visible square at save time with a pure cropper.

Purpose: the expert's public photo looks like the preview they approved.

Output: `ProfilePhotoCropper`, the view model keeping the picked `UIImage` and cropping in `save()`, the slider gated to a newly picked photo, and two test suites.
</objective>

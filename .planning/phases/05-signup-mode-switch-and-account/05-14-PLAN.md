<objective>
SET-06 / D-10, the expert half of "a way to My Bookings", split out of plan 05-08. Plan 05-08's blocker alert shows "View my bookings" only when the shell provides `showMyBookings`. The client shell provides it through `HomeShellExit.plan(.viewMyBookings, selectedTab:)`; the expert shell provides nothing, so in Expert mode the button stays hidden. PATTERNS.md directs the expert shell to copy the client wiring and the same `HomeShellExit` plan, so this plan makes `HomeShellExit` generic over a shell's tab type and installs that plan on the expert shell. It adds no expert-only reset logic.

Purpose: an expert blocked from deleting their account by upcoming bookings goes straight to them, and both shells leave a flow the same way.

Output: a generic `HomeShellExit` with a `HomeShellTab` protocol, the expert shell's `showMyBookings`, expert rows in `HomeShellExitTests`, and the corrected environment doc.
</objective>

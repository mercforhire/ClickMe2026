<objective>
SIGN-06, D-01's Not now, split out of plan 05-07 to keep each plan inside the context budget. Plan 05-07 built the gate that opens the setup hub; this plan gives the hub Android's Not now (D-27), which returns the user to Client mode and is remembered for the login, makes Publish clear it through `completeSetup()`, and clears it when the user asks for Expert again or signs out. Android's shape: `UserManager.deferSetup()` / `completeSetup()`.

Purpose: a user who is sent to the setup hub always has a way out, and is not pushed back into setup on every launch after saying Not now.

Output: `SetupDeferralStore`, the `UserManager` deferral methods, the hub's Not now, Publish's `completeSetup()`, and `SetupDeferralStoreTests`.
</objective>

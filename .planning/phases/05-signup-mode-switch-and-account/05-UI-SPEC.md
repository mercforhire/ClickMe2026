# Phase 05 — UI Design Contract

> Visual and interaction contract for Phase 05: Signup, Mode Switch and Account. Generated by gsd-ui-researcher, to be verified by gsd-ui-checker.
>
> **Scope of this contract.** Phase 05 is a bug-fix phase on a live SwiftUI app. It adds no palette, no spacing scale and no redesign. It locks (1) the design system exactly as the code has it today, inherited from `02-UI-SPEC.md`, `03-UI-SPEC.md` and `04-UI-SPEC.md`, and (2) the new or changed states, copy and interaction rules the 13 Phase 05 requirements (plus T8) and the 16 `05-CONTEXT.md` decisions need: a setup-hub gate with a **Not now** exit, a busy state on Mode Switch, an accurate Delete Account screen (one permanence line, one upfront line, three groups, no Pause card), a blocker alert for the three self-delete 409s, a "Cancellation policy" link on the cancel confirmation, a publish rule that names a missing photo, an optional and clearable province, id-backed language editing, a 10-character feedback rule, and a Login that remembers the last email.
>
> **This spec is written retroactively, mid-execution.** Wave 1 (plans 05-01 to 05-06 and 05-17) is implemented and committed at HEAD `0600b54`. Waves 2 to 6 (05-07 to 05-16, and 05-13) are planned and not built. Every row below carries a **Status**: `shipped` (read in the code at `0600b54`), `planned NN` (specified by `05-NN-PLAN.md`, not yet built) or `contract` (this file's rule where no plan fixes it). Nothing here contradicts shipped wave-1 code except one declared follow-up (the Feedback error weight, see Typography). Three unbuilt plans are refined by one value each, named where they occur: 05-09 (zero-language guard, EM4), 05-08 (`View My Bookings` casing, CP1) and 05-15 (header `spacing: 16`). Where the plans leave a point open, it is recorded in "Assumptions recorded" and in the unresolved rows of "UI Considerations", never silently decided.
>
> **Every copy string in the Copywriting Contract is exact.** Executors must not paraphrase. Where a string comes from a decision, the decision id is cited. Where it comes from a plan, the plan number is cited.
>
> **Live-account warning.** Delete Account is irreversible against the production backend, and the Expert gate may promote a client-only account through `ensureExpert` (D-04). Device checks for those two flows use a throwaway account (see "Device-only checks").

## Spacing Scale

Target tokens for any new or changed layout in this phase (points, multiples of 4):

| Token | Value | Usage on Phase 05 surfaces |
|-------|-------|----------------------------|
| xs | 4 | Gap between a Delete Account group title and its body; icon-to-text gap |
| sm | 8 | Gap between wrapped chips or inline error and its field (existing) |
| md | 16 | `spacing:` of the Delete Account header stack: between the headline, the permanence line, the upfront line and each of the three groups |
| lg | 24 | Top and bottom padding of the Delete Account scroll content (existing 24, kept) |
| xl | 32 | Not used by a new Phase 05 element |
| 2xl | 48 | Not used by a new Phase 05 element |
| 3xl | 64 | Not used by a new Phase 05 element |

The Delete Account header stack (`DeleteAccountWarningHeader`, `VStack(alignment: .leading, spacing: 12)` at HEAD, line 15) is rewritten by plan 05-15, which is not yet built. The contract moves its `spacing:` from 12 to **16 (md)**, on the declared scale. New children (permanence line, upfront line, three groups) are added to that same stack and inherit 16 pt, so the headline, the lines and the groups read as one block. Inside each group the title sits 4 pt (xs) above its body. 8 was rejected because it packs three multi-line groups too tightly under Dynamic Type; 12 pt is not declared as an exception. Plan 05-15 Task 1 must set `spacing: 16` where it rewrites the header (the plan text says only "spaced like the existing header", so this is a one-value instruction to it). No wave-1 code changes: the header is untouched at `0600b54`.

Exceptions declared for new Phase 05 layout: none. Every new interactive control is at least 44 pt tall: the hub's **Not now** is a system toolbar button (44 pt hit target); the blocker alert buttons are system alert buttons.

### Generic-label waiver

Rule: every new Phase 05 call-to-action label is a specific verb plus noun (`Delete Account`, `View My Bookings`). Generic labels (`OK`, `Cancel`, `Save`, `Done`, `Not now`) are **waived, with the reason below**, for exactly the controls in this table, and for no new control. No label in this table is renamed by Phase 05, so the waiver needs no change to shipped code and no change to an unbuilt plan, and iOS keeps parity with Android's wording.

| Label | Where | Reason for the waiver |
|-------|-------|-----------------------|
| `OK` (cancel role) | Publish-blocked alert (`Couldn't publish profile`, shipped), blocker alert dismiss (planned 05-08), generic failure alert (`Couldn't delete account`, shipped), auto-save alert (`Couldn't save changes`, shipped) | System alert dismiss button. The alert title and message carry the specific meaning; `OK` only acknowledges. The alert is informational and offers no choice that a noun would disambiguate. In the blocker alert the specific action is the default button `View My Bookings`; `OK` is its dismiss pair |
| `Cancel` (secondary) | Delete Account bottom button (shipped, unchanged); `LanguageSelectionView` (shipped, unchanged); the real button named in How to Initiate step 3 (shipped) | Established iOS convention for backing out of a confirmation. Existing label, unchanged by this phase, and the same word Android uses. Renaming the Delete Account secondary (for example to `Keep My Account`) would edit shipped code and split iOS from Android for no behavior change |
| `Save` | Signup Profile Photo save button (shipped 05-03, unchanged) | Single-purpose screen titled for the photo; the title supplies the noun. Existing label, unchanged |
| `Done` | `LanguageSelectionView` (shipped, unchanged) | Dismisses a picker that applies its selection on exit. Existing label, unchanged |
| `Not now` | Setup hub exit (planned 05-16) | Locked by D-27 to match Android. It is a deferral, not an action on a noun, and has no more specific honest label |

Phase 05 changes only the words above it and removes the Pause card. Not now, Mode Switch, language edits and the policy link are not destructive and have no confirmation |

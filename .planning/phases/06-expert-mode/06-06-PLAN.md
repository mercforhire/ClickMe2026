<objective>
Two expert-side display fixes: EXP-15 (the hub's online dot is hard-coded `true`, so it is removed, matching Android, D-10) and EXP-12 (expired request cards dim the whole card to 55%, which drops the secondary text to about 3.9:1; text goes back to full contrast and only the fill, border, avatar and badge change, D-17).

EXP-12 is a LIKELY item (ROADMAP Phase 6 note, D-17: "confirm on a device first"). The fix is built now from the contrast arithmetic in 06-UI-SPEC (3.91:1 against a 4.5:1 minimum); the "before" check runs on App Store build 6, which still has the dimmed card, and the "after" check on the new build (device check D1). If D1's before-check finds the text readable, closing EXP-12 as not reproducible is the verifier's call; the change is harmless either way.

Output: the presence property removed from the hub view model and both of its reads replaced; the expired card restyled per the UI-SPEC colour table.
</objective>

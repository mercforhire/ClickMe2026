Every free topic the server stores with no currency opens in the iOS Topic Editor on a blank currency: the backend sends `price.currency: ""` for a NULL `price_currency`, the editor keeps `""` because `??` only skips nil, the picker appends `""` as an invisible third segment, and every Save sends `hourly_rate.currency: ""`, which the PATCH schema rejects with 422. The optional backend `""` to `null` hardening is plan 06-17 and is not needed for this fix. A production backfill of NULL rows is a separate user decision and is not planned anywhere.

<objective>
Gap G-06-1-card-cents (UAT 06 Test 1, checklist item 1; cosmetic). The Topics tab cards show `CA$50 / session` and `US$5 / session` instead of two decimals. The card formats through `Money` only when the payload has an hourly rate, and the server stopped sending `hourly_rate` in `50abd85`, so the card always shows the server `price.label`, which backend `formatPrice.js` deliberately trims (`120.00` becomes `120`). The server label is shared with build 6 and Android, so it is not the place to change.

Purpose: the expert should see the exact amount clients pay, to the cent, the same way every other iOS money surface shows it (Phase 2 BOOK-10, `Money`).

Output: a static `TopicsSetupTopicCard.priceLabel(for:)` that formats `price.amount` in the topic's valid stored currency with the ` / session` suffix, `Free` for free topics, and the server label only as a fallback; a label test table; a read-only Android parity check.
</objective>

CHAT-01 (D-01, D-02, first half of D-03): a sent message appears immediately as a pending bubble, the ack updates that same bubble, a network or server failure leaves a visible Failed bubble, and a refused send gives the text back. Purpose: today `sendMessage()` waits for the server with the composer disabled, shows nothing until the ack lands, loses the text on failure behind an alert, and `forceLoad()` replaces the whole list, so any local row would vanish on pull-to-refresh.

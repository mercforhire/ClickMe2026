<objective>
CHAT-07 on the Chats list (D-12 to D-15): each conversation row shows how many messages are unread, the count clears the moment the thread opens by any route, and a live message from the other person adds to it until the next reload re-syncs from the server.

Purpose: the backend already counts unread messages (BACK-18) and plan 07-03 sends the read receipts that clear them, but `ChatConversationRow` ignores `unreadCount`, the list never changes it locally, and a thread opened from a push or a profile never refreshes the list.

Output: `ChatUnreadRules`, the count rules on `ChatConversationsViewModel`, the pill on `ChatConversationRow`, an observable `ChatPresence` hook in `ChatConversationsView`, and two test suites.
</objective>

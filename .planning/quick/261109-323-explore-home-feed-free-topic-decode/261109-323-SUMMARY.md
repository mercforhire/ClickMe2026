# Quick 261109-323: Explore home feed, free topic decode

Free featured topics with `hourly_rate {amount:0,currency:null}` no longer fail the whole `/client/home` decode on the new iOS code, and a backend migration (committed, not applied) makes `home_feed` send a null `hourly_rate` for them so build 6 stops failing once it is applied.

## What changed

- **Backend:** new migration re-creates `home_feed` from lines 180-358 of `20261016000100`, with only the `hourly_rate` expression changed (`CASE WHEN ft.price_currency IS NULL THEN NULL ELSE json_build_object(...) END`). `homeFeedNullHourlyRate.test.js` proves from the SQL text that nothing else differs. `discovery.test.js` gained one case: a null `hourly_rate` with `is_free: true` passes through the controller.
- **iOS decode:** `HourlyRate.amount` and `currency` are optional, `FeaturedTopic` decodes `is_free`, and featured topics decode per element so one malformed topic is dropped alone. Categories and experts stay strict.
- **iOS label:** `formatPrice` returns "Free" when `is_free == true`, "—" when amount or currency is missing, otherwise the formatted price. No currency is invented.
- **iOS error text:** `NetworkError: LocalizedError` returns one fixed string ("Something went wrong. Please try again."). Explore's private `message(for:)` helper was removed in favor of `Error.userMessage`.
- **iOS stale cards:** a non-cancellation failure sets `featuredTopics = []`; a cancelled reload keeps them.
- **Test plan:** `AllTests.xctestplan` named `ClickMe2026.xcodeproj`, which no longer exists, so `xcodebuild test` found no test bundles. Both container paths now say `ClickMe.xcodeproj` (own commit).

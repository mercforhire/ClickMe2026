Engineering, each item with its backing file
- `actor TokenRefresher` (`ClickMe2026/Network/NetworkService.swift`, around line 383) makes concurrent 401s share one in-flight refresh, then retries the original request once. This is needed because the backend detects reuse of an old refresh token and revokes the whole session. A 403 ACCOUNT_SUSPENDED goes to `suspensionHandler`.
- `Error.userMessage` (`ClickMe2026/Network/Error+UserMessage.swift`) turns any error into display text, preferring the server's message. `ClickMe2026/Model/Enums/ErrorCode.swift` lets the UI branch on error codes instead of matching strings.
- Concurrency: Swift 6 complete strict checking. Managers and view models are `@MainActor`, `TokenRefresher` is an actor, and the Agora delegate callbacks in `ClickMe2026/Managers/AgoraManager.swift` are `nonisolated` and hop to the main actor.
- `ClickMe2026/Utils/JoinWindow.swift` is the one rule for showing Join. The status must be confirmed, in progress or completed. Join opens 60 minutes before the start. A first join stays possible until the later of the scheduled end and 60 minutes after the start. A server-approved reconnect is allowed for 60 minutes after the end. The caller passes the clock in (`now`), and the server keeps the final say. The rule mirrors the backend's.
- `ClickMe2026/Managers/CallCenter.swift` allows at most one active call.
- Pure policy types under `ClickMe2026/Utils/` (for example `ClickMe2026/Utils/CallOvertimePolicy.swift` and `ClickMe2026/Utils/ConfirmRetryPolicy.swift`) are unit tested in `ClickMe2026Tests/Utils/`.
